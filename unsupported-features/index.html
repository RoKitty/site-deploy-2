Unsupported features¶

RoKitty aims to implement all the core features of Roblox, allowing you to use the RoKitty interface for as many actions on the Roblox platform as possible. However, you can't use RoKitty to do everything you can do on Roblox.com. Most features are planned and just aren't done yet, but some just aren't feasible for RoKitty to implement for security, privacy, or other technical reasons.

RoKitty never locks you in, so whenever a feature is missing you can always use Roblox.com or the Roblox app to fill the gap.

As RoKitty is under development and Roblox is always changing, a complete list of missing features is not available. If you need information about a specific feature, please get in touch.
